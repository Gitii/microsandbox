## Browse by workflow

- **Agents**: OpenCode, OpenClaw, Goose, Gemini CLI, Hermes Agent, Pi, and a tool-agnostic coding-agent pattern.
- **CI/CD**: Hermetic PR checks, Docker Compose integration tests, and time-limited preview deploys.
- **Automation**: Scheduled dependency audits and parallel batch dispatch.
- **Plugins**: Extism WebAssembly modules, Terraform providers, and third-party ESLint plugins.
- **Web Automation**: Playwright browser jobs and bounded Scrapy crawls.
- **Systems and data**: Docker, systemd, VNC, PostgreSQL, Redis, migrations, metrics backends, and file processing.
